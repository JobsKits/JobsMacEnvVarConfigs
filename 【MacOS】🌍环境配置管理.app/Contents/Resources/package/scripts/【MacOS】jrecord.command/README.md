## 🔥 <span id="前言">前言</span>

> 从终端选择一个浏览器或应用窗口录制，默认无声音，不需要框选区域。入口为同目录 [【MacOS】jrecord.command](./【MacOS】jrecord.command)，原生采集内核随 [Core](./Core/README.md) 一起分发。

包目录与入口统一使用调用名：`【MacOS】jrecord.command/【MacOS】jrecord.command`，终端短命令为 `jrecord`。

参考自 [**screcord**](https://github.com/bcharleson/screcord)，扫描其源码后提炼窗口录制流程，并按 Jobs 的脚本规范独立改写。

## 一、<span id="features">当前能力与边界</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 能力 | 当前行为 |
| --- | --- |
| 浏览器窗口 | 默认列已识别浏览器中有效且有标题的应用窗口，包括最小化或其它空间中的有标题窗口；隐藏状态标注 `[隐藏]`。一个 Chrome 窗口包含两个标签页时只显示一条，标题通常为当前激活标签页，不将标签页当成独立窗口 |
| 辅助范围 | `--all` 只切换浏览器／全部应用范围；普通菜单不提供辅助显示开关，无标题辅助候选默认不显示。只有启动时显式传入 `--include-auxiliary` 才进入诊断模式，额外包含并标注这些窗口 |
| 精确目标 | 使用真实窗口 ID、PID、应用 Bundle ID 和进程启动时间组成身份快照，录制前再次复核 |
| 菜单查询 | 窗口、录制确认、声音和帧率菜单返回重入时保留仍有效的查询；本层候选或录制目标改变时清空。状态只在当前进程保留，关闭后不落盘；健康探针和菜单均清除继承的 fzf 默认选项 |
| 录前倒计时 | 确认保存地址后显示 5 秒屏幕倒计时；提示层允许鼠标穿透，不抢占键盘焦点，倒计时结束并移除后才开始采集 |
| 画面范围 | 采用 [ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit) 独立窗口过滤，包含该窗口的地址栏和标签切换；其它应用遮挡不会进入画面，绝不降级整屏或区域录制 |
| 声音 | 默认静音 `none`；子菜单明确选择静音或录制系统／应用声音 `system`，显示当前值，不提供麦克风或音量增益。系统音频不能保证隔离同一应用的其它窗口；要求没有其它声音时保持静音 |
| 帧率与时长 | 默认 30 FPS；子菜单提供 15／24／25／30／50／60 FPS 和纯数字手动输入，合法范围 1–60 FPS；可定时停止，最多 86400 秒，或按 Ctrl+C 保存 |
| 画布 | 初始窗口像素比例，最大边 3840；窗口变尺寸时保持比例适配既定画布，不动态改视频分辨率 |
| 保存 | 真正的单个 MP4；先独立暂存，封尾并验证可读、正时长和视频轨道后，以原子排他方式发布；已有文件、目录及悬空符号链接均拒绝覆盖 |
| 保存地址与完成操作 | 未传 `--output` 时，采集前询问保存目录，空回车使用系统桌面；成功发布后询问是否打开所在目录，默认“不打开”，不会自动播放视频 |
| 终端关闭 | 关闭启动终端、PTY 断开或启动父进程强退均停止本次采集并尽力封尾保存；不遗留后台录制。无控制终端的自动化调用只监视父进程 |
| 异常 | 启动、首帧、窗口枚举、停止、封尾和媒体校验有期限；关闭窗口结束录制，其它故障返回非零并保留暂存内容 |
| 依赖 | Apple 系统框架，无第三方 Swift 包、FFmpeg 或浏览器插件；只有交互菜单需要 [fzf](https://formulae.brew.sh/formula/fzf) |

这是窗口录制工具，不包含上游的整屏、区域、摄像头、麦克风、暂停或分段功能。最低 **MacOS 15**，使用系统原生 `SCRecordingOutput` 写入视频；不会自动升级操作系统。

## 二、<span id="usage">运行与键盘操作</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

在本目录运行，或直接双击入口：

```zsh
./【MacOS】jrecord.command
```

通过仓库原有环境同步入口部署后，可直接使用 `jrecord`。全局环境同步由仓库原有入口负责，本工具不会自动运行全仓安装器或修改 Shell 启动配置。

- 先阅读自述，回车同意本轮准备，Ctrl+C 取消；从 `list` 进入时，此确认界面直接按 `←` 返回原功能菜单，无须先确认。确认前不安装、不编译、不采集。
- 窗口列表使用 ↑ / ↓ 或 Tab 选择、回车确认；`←` 或相应的“返回功能菜单／返回终端”选项回到实际来源：从 `list` 进入时返回原功能菜单，直接运行时返回终端并提示“已返回终端”，不递归打开新菜单；Esc 取消本轮。列表单位是应用窗口，标题通常来自当前激活标签页；最小化或其它空间中的有标题正常窗口仍可找到，并标注 `[隐藏]`。普通菜单保留返回、取消、重新加载、切换浏览器／全部应用及真实候选窗口；没有窗口时仍可重新加载或切换范围。
- 列表标题持续显示当前应用范围、普通／诊断模式和实际窗口数量，不把操作行计入窗口数。空态只属于当前列表，重新加载发现窗口后立即替换，不在列表上方遗留旧的“没有可录窗口”日志。
- 仅诊断时使用 `jrecord --include-auxiliary`；此时标题明确标注“诊断窗口（含辅助）”。正常录制使用不带该参数的 `jrecord`。
- 进入录制配置后，“声音设置”和“帧率设置”分别打开明确的子菜单，配置行本身不直接切换数值。配置层默认高亮“返回窗口选择”，普通回车不直接开录。
- 帧率子菜单显示当前值，可选择 15／24／25／30／50／60 FPS，或进入“手动输入数字帧率”。声音子菜单显示当前选中项，只提供“静音”和“录制声音”两种模式；回车设值后回到录制配置。
- 手动帧率按键级只接收 ASCII `0`–`9`，支持退格修改、回车提交。空值、0、超过 60 或过长输入持续重问，合法输入才改变当前帧率；逐键字母、符号和其它字符不进入缓冲，带边界的粘贴只要含字母、符号等非数字正文就拒绝整段。粘贴中的 CR／LF 换行只忽略，不构成提交；纯数字粘贴也必须结束后再按一次真实回车才能生效。输入全程不会执行文本表达式。
- 返回严格按层级进行：录制配置 `←` 回窗口选择；帧率／声音子菜单 `←` 回录制配置；数字输入 `←` 回帧率子菜单且保留原值。即使搜索没有匹配，菜单 `←` 仍可返回；这些录制前页面的 Esc／Ctrl+C 均取消本轮。
- 明确选择“开始录制”后，未传 `--output` 时先询问保存目录；空回车使用系统桌面。可输入或拖入含中文、空格的现有目录，路径按字面解析，不执行表达式；目录不存在或不可写时持续重问，输入结束或 Ctrl+C 取消且不采集。
- 显式 `--output` 尊重完整文件路径，不再额外询问地址；非交互录制必须给出该参数，不会静默保存到默认位置。
- 保存地址确认后显示 5 秒倒计时，期间可直接点击并操作下面的目标窗口；倒计时不计入录制时长，也不进入最终视频。Ctrl+C 在倒计时期间取消并返回 130，尚未开始采集，不生成录制文件。
- Ctrl+C 在录制期间是正常的停止保存请求，成功发布最终 MP4 后仍会询问是否打开文件所在目录；默认高亮“不打开”，可用方向键或 Tab 选择，回车确认。此时 `←` 或相应返回项直接返回原 `list`／终端，不打开目录，也不会回到录制配置或再次录制已保存文件；Esc 仅不打开并正常结束。输入结束、非交互调用、失败或没有最终输出均不打开目录。准备阶段 Ctrl+C 仍取消整个任务。
- 关闭启动终端同样停止录制；内核每约 100 毫秒检查启动父进程关系与原控制终端的挂断状态，即使父 Shell 被 `SIGKILL`、没有机会转发 HUP，也会主动结束采集并尽力保存有效片段。倒计时中终端关闭则取消且不录制。直接强杀原生录屏内核本身、系统断电或崩溃无法执行封尾；这类异常不承诺最终 MP4 完整，已有暂存内容保留。无控制终端的已授权自动化调用正常运行，不因没有 TTY 就立即退出。
- 媒体清理最多预留 95 秒，仅向本次身份匹配的原生内核请求结束，日志 `tee` 随输出 EOF 自然退出；超时也只中断该内核。准备或下载阶段最多预留 10 秒，回收本次身份匹配的进程树，不向共享进程组发信号。

首次缺少屏幕录制权限时，系统会要求给启动本工具的终端授权；在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”完成后可能需要重新启动终端。脚本不绕过授权，也不自动勾选设置。

## 三、<span id="commands">命令参数与示例</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

下列示例在完成环境同步后使用 `jrecord`；源码直接运行时，把它替换为本目录的 `./【MacOS】jrecord.command`。

```zsh
# 安全查看帮助；任何位置的 --help 都优先返回，不会开始录制
jrecord --help

# 只读体检：不安装、不编译、不申请权限
jrecord --doctor

# 本轮明确授权补齐依赖和编译，完成后退出，不录制
jrecord --prepare --yes

# 显式请求系统录屏授权，不录制
jrecord --permission

# 列出浏览器窗口；输出 ID / 应用 / 标题 / 尺寸，不输出内部凭据
jrecord --list
jrecord --list --all
jrecord --list --all --include-auxiliary

# 将 12345 替换为本次 --list 返回的真实窗口 ID；不是列表序号
# --yes 同时授权该明确窗口的录制；不传 --yes 则需再次确认
jrecord --window-id 12345 --duration 30 --audio none \
  --output "$HOME/Desktop/browser-demo.mp4" --yes

# 在交互中列出所有应用，并保持鼠标指针隐藏
jrecord --all --fps 60 --no-cursor
```

| 参数 | 含义／默认值 |
| --- | --- |
| 无参数 | 交互选择浏览器窗口与配置，帧率／声音分别进入子菜单，最后明确开始 |
| `--all` | 交互或列窗时使用全部应用有标题窗口范围；不会自动显示无标题辅助候选 |
| `--include-auxiliary` | 启动时显式进入诊断模式，额外包含无标题辅助候选（含隐藏），与 `--all` 独立；普通菜单无法切入，有标题正常窗口即使已最小化或在其它空间也无需此参数 |
| `--window-id ID` | 精确取得该窗口身份快照后复核录制；窗口 ID 可能变化，应重新列出 |
| `--output PATH.mp4` | 新 MP4 路径；显式指定时不再询问保存地址，相对路径以调用时工作目录解析，父目录必须存在且可写；省略时仅交互询问目录，默认系统桌面 |
| `--duration SEC` | 大于 0、最多 86400 秒；省略则持续到停止 |
| `--fps N` | 1–60 的整数，默认 30；交互可选预设或纯数字手动输入 |
| `--audio none\|system` | 默认静音 `none`；交互子菜单显示中文说明和当前选择，`system` 可能包含同一应用其它窗口声音 |
| `--no-cursor` | 不录指针，默认显示指针 |
| `--list` | 只列窗口，不录制 |
| `--doctor` | 只体检；报告系统、编译器／SDK 和交互依赖，不修复、不采集 |
| `--prepare` | 健康检查、条件式补齐、复检并编译内核，不录制 |
| `--permission` | 显式走系统屏幕录制授权，不录制 |
| `--yes` | 授权本轮准备；指定 ID 时同时授权录制。不会跳过未指定 `--output` 时的保存地址询问；非交互录制必须给出 `--output`。默认交互模式仍保留最终开始菜单，不代替系统权限及首次 Homebrew 安装路径选择 |
| `--no-repair` | 不安装或修复依赖；已就绪时仍可编译随包源码 |
| `--help` / `--version` | 显示帮助／版本，不创建日志或编译缓存 |

`--doctor`、`--prepare`、`--list`、`--permission` 不能相互叠加，也不能与 `--window-id` 混用。未知选项、空值、无穷值、非法帧率和时长均在准备之前拒绝。

## 四、<span id="health">依赖体检、补齐与复检</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

依赖链按实际执行路径拆分：

```text
原生录制 → Swift 编译器 + MacOS 15+ SDK → Xcode / Command Line Tools
交互菜单 → fzf → 仅缺失或损坏时使用健康的 Homebrew
最终录制 → 屏幕录制权限 + 真实目标身份 + 可写输出目录 + 至少 256 MB 可用空间
```

- 每层先发现路径，再执行版本／SDK／实际选项检查；编译后的内核还须通过纯逻辑及文件发布自检。健康依赖直接复用，不执行整个环境升级。
- 工具链缺失时调用 Apple 官方安装器，安装器接管后持续等待并复检，不重复弹出窗口；已有工具链缺少兼容 SDK 时查询 Apple 正式更新目录并安装对应 Command Line Tools。
- SDK 获取的网络失败持续退避重试，可随时 Ctrl+C 结束；权限、许可证、认证、磁盘或没有可用组件属于明确阻塞，不伪装成下载成功，也不自动接受许可证。
- fzf 缺失或实际选项检查失败时，沿 Homebrew 的“发现 → 命令健康检查 → 安装／修复 fzf → 当前进程 PATH 刷新 → 再次验证”处理。Homebrew 官方元数据、稳定版本与 fzf 的临时网络失败持续退避重试并保留已有缓存；取消、权限／磁盘／许可、错误响应和复检失败立即停止，不重复安装路径确认。获取函数通过临时原生子解释器交给原有进程树管理，HTTP 状态只在函数内捕获；不改变录屏子进程的信号与保存协议。
- 首次缺少 Homebrew 时遵循本仓原有路径选择：精确 `YES` 选择系统标准目录，其它输入／直接回车选择用户目录；系统权限由官方安装器处理。不自动改全局 PATH、Shell 配置、代理或安装来源。
- 构建缓存由源码内容、编译器信息、SDK 与架构共同标识；各调用使用独立目录，成功自检后才标记可复用。损坏或未完成的缓存保留原状，不接管别人的构建锁。

无法满足硬件／系统版本、许可或系统权限时会明确停止；这些条件需要在系统官方入口处理，不能通过脚本绕过。

## 五、<span id="files">文件、日志与迁移</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

```text
【MacOS】jrecord.command/
├── 【MacOS】jrecord.command    # 自述、依赖门禁、菜单与进程生命周期
├── README.md
├── Core/                      # 随包原生源码，按职责分目录
└── Tests/                     # 隔离回归，不参与日常录制
```

- 默认视频：采集前询问保存目录，空回车使用当前用户的系统桌面；文件名为 `窗口录屏-年月日 时分秒-PID.mp4`。默认路径不依赖启动工作目录，不自动创建输入的未知目录。显式 `--output` 使用指定文件路径。
- 成功发布后可选择用系统 `open` 打开最终文件所在目录，默认不打开；该操作只定位目录，不播放视频，不修改录制结果。录后 `←` 直接返回来源菜单／终端，不重新进入录制；非交互调用不会打开目录。
- 暂存视频：输出目录内独立的 `.JobsWindowRecorder-UUID/recording.mp4`。失败不发布最终文件，保留暂存内容并报告实际路径；是否仍能播放取决于系统是否成功封尾。
- 缓存：`${XDG_CACHE_HOME:-$HOME/Library/Caches}/JobsWindowRecorder/`，每个完成目录有 `.ready`。正常运行不清理其它调用的缓存。
- 日志：`${TMPDIR:-/tmp}/jobs-window-record.XXXXXX/record.log`，会话目录权限仅当前用户可用。日志保留进度、错误和产物路径，不写窗口标题或内部身份凭据；显式列窗时标题只输出到当前终端。
- 完整提示消息和 Homebrew 固定版本获取的三层日志使用内联标准纯文本端点，URL 样式只进入人类展示；三路写入失败保留为 74，原生取消码保持。获取 worker 在创建前核验全部可信函数，缺失即停止。原生托管命令保持即时交互，未整流套行缓冲渲染；完成后的 `run_captured` 展示副本可着色、追加日志去色，原始 capture 文件逐字节保留。
- 分发时复制整个同名目录，包括 Core。源码入口、环境函数和安装后的短命令转发器均定位完整包；不依赖本机下载的 `3rd/screcord`，不把构建产物作为源码分发。
