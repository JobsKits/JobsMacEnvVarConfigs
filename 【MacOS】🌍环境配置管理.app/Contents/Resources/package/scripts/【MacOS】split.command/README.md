## 🔥 <span id="前言">前言</span>

在 [**MacOS**](https://www.apple.com/macos/) 将大文件按字节拆成可由 [jmerge](../【MacOS】merge.command/README.md) 还原的分卷。每次必须手动输入或拖入目标，空输入不使用默认目录。

## 一、功能与边界 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 能力 | 行为 |
| --- | --- |
| 手动目标 | 输入一个目录或普通文件；支持中文、空格、引号和终端拖入转义；不执行输入中的代码，不接受命令行路径参数。 |
| 持续校验 | 路径不存在、空白、多路径、符号链接、目录不可读 / 不可进入 / 不可写、没有可拆文件时重新询问；EOF 或 Ctrl+C 终止。 |
| 文件范围 | 只扫描目录第一层；不递归。源文件必须可读、至少 2 字节；跳过隐藏文件、`@序号of总数` 分卷及输出目录已被占用的文件。 |
| 上限 | 默认 50 MiB，另有 100 MiB、1900 MiB、自定义 MiB；自定义支持小数，换算后至少 1 字节。 |
| 分卷 | 文件必须超过上限；先确定卷数，再均摊大小，每卷不超过所选上限。没有符合上限的文件会重问目标，再重新选择上限。 |
| 防覆盖 | 已有分卷目录、文件或同名链接不覆盖。失败 / 中断保留源文件及临时结果。 |
| 完整性 | 检查卷数、总字节数和 SHA-256；通过后排他发布完整目录，再检查发布后的分卷。 |
| 删除 | 默认保留源文件；校验通过后，只有精确输入大写 `YES` 才删除原文件，其它输入或 EOF 均保留。 |

## 二、运行与操作 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

从本目录运行，也可双击脚本：

```shell
zsh './【MacOS】split.command'
```

通过仓库环境同步入口部署后，在终端运行：

```shell
jsplit
```

- 阅读内置自述，按回车继续；Ctrl+C 取消。
- 手动输入或拖入一个目标目录，也可直接拖入一个文件；输入无效时持续询问。
- 在分卷上限面板用 ↑/↓ 或 Tab 移动、回车确认；Esc 或“取消本轮”结束。自定义上限空回车返回标准选择。
- 目录模式进入文件多选：↑/↓ 或 Tab 移动，回车勾选 / 取消；“全选”“清空”“取消本轮”均可用方向键定位并回车操作。Ctrl+A 全选、Ctrl+D 清空为快捷键；在真实文件行按空格确认，空选不执行。`←` 返回上限选择，查询无匹配时也可返回。
- 单文件模式省略多选；执行前均显示来源、输出目录和上限。最终确认默认选中“取消本轮”；选择“开始拆分并校验”后回车才写入，`←` 返回上一层，Esc 取消。
- 完成并校验后逐个询问是否删除源文件；直接回车保留，精确 `YES` 才删除。

## 三、产物与依赖 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

例如 `资料/镜像.iso` 拆成三卷：

```text
资料/
├── 镜像.iso
└── 镜像/
    ├── 镜像.iso@1of3
    ├── 镜像.iso@2of3
    └── 镜像.iso@3of3
```

卷号在需要时统一补零；无扩展名的 `资料/镜像` 输出到 `资料/镜像.parts/`。已有输出不会复用，需先移动旧结果或另选目标。失败临时结果使用源目录中的 `.split.随机后缀/`，位置会显示在终端和日志中。

解释器为系统 zsh；业务依赖系统 `split`、`stat`、`shasum`、`find`、`mktemp`、`cat`、`mv`、`awk` 与 `osascript`，交互依赖 [**fzf**](https://github.com/junegunn/fzf)。脚本只检查，不安装、不升级工具，不修改 Shell 配置。缺少 fzf 时可自行通过 [**Homebrew**](https://brew.sh/) 安装：

```shell
brew install fzf
```

独立脚本包无需其它仓库；复制整个同名目录后可从任意工作目录运行。系统 `split` 继续使用 `/usr/bin/split`，短命令 `jsplit` 不占用它。

日志位于系统临时目录，文件名为 `【MacOS】split.log`，仅记录纯文本。支持可靠读取与恢复配色的终端临时使用黑底白字，退出后恢复；未知终端、非 TTY、`NO_COLOR` 等场景降级为纯文本。强制杀进程无法保证自动恢复，使用运行时显示的独立恢复入口。

## 四、流程与验证 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

流程保留 [**Mermaid**](https://mermaid.js.org) 源码：

```mermaid
flowchart TD
    A[展示自述并回车确认] --> B[检查系统工具和 fzf]
    B --> C[手动输入或拖入目标]
    C --> D{路径和文件有效?}
    D -->|否| C
    D -->|是| E[选择分卷上限]
    E --> F{有超过上限的文件?}
    F -->|否| C
    F -->|是| G[单文件或明确勾选文件]
    G --> H{最终确认 默认取消}
    H -->|目录模式返回| G
    H -->|单文件返回| E
    H -->|取消| I[结束 不写入]
    H -->|开始| J[临时拆分并校验后排他发布]
    J --> K{精确 YES 且复检成功?}
    K -->|是| L[删除原文件]
    K -->|否| M[保留原文件]
```

隔离回归入口与验证范围见 [测试说明](./Tests/【MacOS】FilePartsTests.zsh/README.md)；仅测试临时文件，不处理用户真实大文件。
