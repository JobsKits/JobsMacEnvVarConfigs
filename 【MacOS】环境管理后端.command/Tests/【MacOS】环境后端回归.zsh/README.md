## 🔥 <span id="前言">前言</span>

[【MacOS】环境后端回归.zsh](./【MacOS】环境后端回归.zsh) 使用系统 [**zsh**](https://www.zsh.org/) 与文件工具，实际在全新临时 HOME 中复制、备份和恢复文件；不安装或卸载当前用户环境，不运行部署后的工具业务。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">一、运行方式 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

在本 README 所在目录执行：

```shell
/bin/zsh ./【MacOS】环境后端回归.zsh --yes
```

测试从自身位置定位[管理后端](../../【MacOS】环境管理后端.command)，将需要的完整来源复制到中文、空格路径，并从原源码以外的工作目录执行。每轮创建不同夹具，输出每项结果、检查数量和日志位置；保留现场，不清空旧输出。

## <span id="jobs-toc-heading-3" data-jobs-toc="v2">二、覆盖边界 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

- 50 项实时四列目录（6 个配置／支持组件及 44 个命令组件，含 `cmd-orc`）、全部计划、未知 ID、混入 `all` 的错误、缺少授权与只读零写入。
- 单选命令、自动补齐依赖、未选命令缺席、完整功能包、生成配置语法与组件状态。
- 原 `.zshrc` 完整字节、重复安装幂等、原同名命令内容与权限恢复、重复卸载。
- 用户后来修改时保留整个组件，拒绝覆盖与不完整卸载；符号链接原件保护。
- 历史无收据对象保留、未选命令依赖和无收据自定义共享引用保护。
- 全部组件文件安装／卸载、媒体格式转发入口、录屏 Core 随包资源。
- 完整源码复制移动、缺少输入文件、计划后 `.zshrc` 并发修改时拒绝旧候选发布。

每个组件只验证部署文件、收据与恢复行为，不将这些结果等同于依赖安装、图形面板、真实终端按键、录屏权限、工具实际业务或真实用户安装／卸载验收。
